# 系统干预器 (System Intervenor)

> **⚠️ 状态提示：作为类似任务管理器的程序，该项目已终止维护。**

系统干预器是一个拥有精美现代化界面的高级类任务管理器工具，致力于提供更直观、顺滑的系统硬件与进程资源监控体验。

## 💻 软件用途

本软件旨在替代传统任务管理器，为极客和高级用户提供更现代的可视化界面。支持深浅色无缝切换，在保证美观的同时，实现对系统硬件负载、后台进程活动以及网络流量去向的实时捕捉和快速干预。

## ✨ 核心功能

* **高刷系统仪表盘 (Dashboard)**
  * **实时物理状态监控**：直观展示 CPU、内存、多块磁盘以及 GPU(s) 的真实使用率。
  * **底层硬件探测**：采用 `CallNtPowerInformation` 和 `psapi` 底层接口读取 CPU 实时动态睿频、系统全局线程数及句柄数。
* **深度进程管理 (Process Control)**
  * **集群式进程树**：将相关联的主进程与子进程智能折叠，界面整洁不杂乱。
  * **快速干预系统**：提供一键内存清理优化，支持选中进程并执行强制阻断（Kill）。
* **进程级网络审计 (Network Analyzer)**
  * **分流追踪**：不只是全局网速，精准捕获每个带有网络通信应用程序的实时上下行速度。
  * **心跳式微图表**：各应用内置 60 帧独立滑动的流量趋势图，结合平滑排名算法，确保高频刷新不闪烁。
* **极客性能控制**
  * **模块性能休眠**：在侧边栏右键对应功能图标，可直接挂起（禁用）该页面的后台数据拉取引擎，释放监控程序本身的性能开销。
  * **全局丝滑切换**：内置平滑的页面切换渐隐渐入补间动画，提供极为舒适的交互感。

## 🚀 如何使用

### 方式一：独立运行（推荐）
如果您拥有打包好的 `系统干预器.exe`：
1. 请直接双击运行可执行文件。
2. （建议使用 **管理员身份** 运行，以获取完整的网络 PID 映射和底层硬件调用权限）。

### 方式二：源码部署
1. 确保本地环境已配置 `Python 3.10+`。
2. 克隆本仓库并安装核心依赖：
   ```bash
   pip install PyQt6 psutil
   ```
3. 在项目根目录启动：
   ```bash
   python main.py
   ```
