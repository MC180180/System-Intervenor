# 系统干预器 (System Intervenor)

[状态：已终止维护]

系统干预器是一个拥有现代界面的类任务管理器工具，提供直观的系统硬件与进程资源监控体验。

## 软件用途

用于替代传统任务管理器。支持深浅色无缝切换，可实时监控系统硬件负载、后台进程活动以及网络流量去向，并支持对异常进程进行快速干预。

## 核心功能

* 仪表盘 (Dashboard)
  * 物理状态监控：直观展示 CPU、内存、磁盘和多显卡的真实使用率。
  * 底层硬件探测：调用系统底层接口读取 CPU 实时动态睿频、全局线程数及句柄数。
* 进程管理
  * 进程树分组：自动将关联的主子进程折叠，保持列表整洁。
  * 快速干预：支持一键内存清理优化，支持强制阻断指定进程。
* 网络追踪
  * 分流审计：精准捕获每个联网程序的实时上下行速度，而非局限于全局网速。
  * 流量微图表：各应用内置独立滑动的流量趋势图，结合平滑排名算法，确保高频刷新下界面不闪烁。
* 极客性能控制
  * 模块休眠：右键侧边栏图标可挂起该页面的后台数据引擎，释放监控工具自身的性能开销。
  * 全局动画：内置平滑的页面切换渐隐渐入动画，交互更流畅。

## 如何使用

### 方式一：独立运行
如果你有打包好的 `系统干预器.exe`：
1. 直接双击运行即可。
2. （建议使用管理员身份运行，以获取完整的网络 PID 映射和底层硬件调用权限）。

### 方式二：源码部署
1. 确保本地安装了 Python 3.10+。
2. 安装核心依赖：
   ```bash
   pip install PyQt6 psutil
   ```
3. 在项目目录启动：
   ```bash
   python main.py
   ```
